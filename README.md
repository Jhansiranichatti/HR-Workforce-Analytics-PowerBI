# HR Workforce Analytics – Power BI

## 📊 Project Overview

This project analyzes workforce data for a multinational organization using **Microsoft Power BI**. The dashboard provides an interactive view of employee demographics, workforce status, departments, job roles, and employee experience.

The goal is to transform workforce data into clear, meaningful insights that can support **HR reporting, workforce planning, and management decision-making**.

---

## 🎯 Project Objectives

* Analyze overall workforce composition and employee status.
* Understand workforce distribution across departments and job titles.
* Analyze employee experience and workforce trends.
* Create interactive HR dashboards using Power BI.
* Present key workforce metrics through KPI cards and visualizations.
* Generate data-driven insights to support workforce management.

## 🔍 Key Insights

The analysis provides several useful workforce insights:

* **Active employees represent the majority of the workforce**, providing an overview of the organization's current workforce strength.
* Workforce status analysis provides visibility into **active, resigned, retired, and terminated employees**.
* Department and job-title analysis helps identify how employees are distributed across different areas of the organization.
* Employee experience analysis provides additional insight into workforce composition and supports workforce planning.
* Interactive Power BI visualizations make it easier for HR and management teams to explore workforce patterns.
